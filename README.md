# \# Message Printer

# 

# A simple Java console application that prints messages.

# 

# \## Features

# 

# \- Prints a welcome message.

# \- Prints a goodbye message.

# \- Displays the current time.

# \- Displays author information.

# 

# \## Requirements

# 

# \- Java JDK 11 or newer.

# 

# \## How to Run

# 

# Compile the program:

# 

# ```bash

# javac MessagePrinter.java

# ```

# 

# Run the program:

# 

# ```bash

# java MessagePrinter

# ```
